# 🚀 Exercícios - Programadores do Amanhã

Este repositório contém as atividades e exercícios do programa **Programadores do Amanhã (PDA)**.  
Os exercícios estão organizados por **módulo (m1, m2, ...)** e por **semanas (s1, s2, ...)**.

---

## 📂 Estrutura

```
EXERCICIOS-PDA/
├── m1/                  # Módulo 1
│   ├── s4/              # Semana 4
│   │   ├── atividade2.js
│   │   └── README.md
├── .gitattributes
└── README.md            # Você está aqui
```

---

## 🛠️ Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/maxine/exercicios-pda.git
   cd exercicios-pda
   ```

2. Navegue até o módulo e seção desejada:
   ```bash
   cd m1/s4
   ```

3. Execute o arquivo no Node.js:
   ```bash
   node atividade2.js
   ```

---

## ✅ Convenção de commits

Para manter o histórico organizado, use mensagens no formato:

- `m1/s4: adicionar atividade 2`
- `m1/s2: corrigir lógica do exercício 1`
- `docs: atualizar README do repositório`
